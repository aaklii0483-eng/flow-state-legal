Terms of Service

1. Scope

FLOW STATE AI SYSTEM is a private/internal tool. This policy distinguishes its current Excel-based functionality from a planned read-only TikTok sandbox integration. The TikTok integration is not currently implemented. Its intended account access is limited to the operator's own or explicitly authorized TikTok accounts.

2. Current information processed

The application processes information supplied in an Excel workbook. This may include content identifiers, publication details, descriptions, URLs and aggregate performance metrics; brand names, contact-person details, payment information and notes; campaign terms, progress, payment states, amounts and dates; content-brand associations, qualification inputs and creative ideas.

The current application does not retrieve information from TikTok. A manually supplied comment count is an aggregate metric, not a collection of individual comments.

3. Current purposes and processing

Information is used to validate records, apply confirmed business rules, assess qualification, identify missing information, calculate supported metrics, and generate decision-support reports. The application reads the workbook without modifying it and processes records in memory. It prints a JSON report that may contain source records, notes and calculated outputs.

The application does not automatically save reports or create a database. Output may nevertheless be retained by an operator or execution environment.

4. Planned TikTok integration

The planned read-only integration is intended to support content-performance analysis using authorized TikTok information. Requested permissions, returned fields, authorization-token handling, storage and refresh behavior will be documented before the integration processes TikTok information.

5. Other services and storage

The inspected application code contains no network requests, advertising integration, analytics tracking, or external AI processing. Hosting or execution providers may process technical information according to their own infrastructure and policies.

6. Retention, deletion and rights

The application has no built-in retention schedule or deletion-request workflow. Workbook files and any retained reports, logs or backups depend on the operating environment. For questions or requests concerning access, correction, deletion, or other applicable data-protection rights, contact aaklii0483@gmail.com.

7. Public-page privacy

The application itself contains no browser cookies or tracking functionality. These public legal pages contain no application analytics, advertising, forms, external fonts, or application cookies.
